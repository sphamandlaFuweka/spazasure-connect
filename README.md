# SpazaSure Connect

The page people open when they scan the QR on SpazaSure's event cards:
https://sphamandlafuweka.github.io/spazasure-connect/

- `index.html` - the contact page (WhatsApp, call, email, website, Facebook, LinkedIn, save contact)
- `print-card.html` - the A5 event card; open it in a browser and print
- `SpazaSure-card-A5.pdf` - the same card, ready for the printer
- `qr-code.svg` - the QR on its own

Printed cards point at this address, so don't rename the repo or turn off Pages.
